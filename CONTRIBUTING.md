# Contributing

This repository candidate is not published yet. Do not upload private backup files, real message/contact data, console tokens, phone identifiers or unredacted reports.

Run `python -m unittest discover -s tests -v` before proposing changes. For full synthetic process/browser checks, follow `tests/device_lab/README.txt`. Clearly distinguish simulated checks from real Windows/USB/device tests. Preserve the read-only design and fail-closed verification: a failed hash or incomplete copy must never be counted as verified.

Contributions, if later accepted, are accepted under the same GPLv3-or-later license and must preserve existing copyright/license notices, including the retained MIT notice for inherited CableVault code. Add appropriate attribution for new work and disclose all new third-party dependencies and licenses. A public contribution process and support response commitment have not been set.
