Your Android data. Your PC. Your choice.

Choose what to copy.
Keep the originals on your phone.

Back up readable files and permitted contacts, SMS, MMS or call logs over USB. Pick only what you need. Nothing is installed, created or deleted on the phone by this app.

Not a full-phone backup or a safe-to-reset guarantee.Android may block providers or files. Media filters use file extensions, and exclusions can omit wanted data. Provider exports are archives, not tested restore backups. Windows 10/11 x64 package. A previous version has one user-reported successful run; this candidate has not been independently tested on Windows or a real phone.

Choose your backup

For example /sdcard/DCIM/Camera, /sdcard/Download, or /storage/ABCD-1234/DCIM. Include subfolders. This is a phone path, not a Windows path.

Media choices match common filename extensions, not actual image/video content. Unknown or missing extensions can be missed. They do not include contacts or messages unless selected below.

Unselected providers are not queried. Android may deny any selected category; no bypass is attempted.

Uncheck to exclude. Hidden means a path component starts with a dot, such as .privacy. Cache matching uses folder names cache, caches, .cache, code_cache, thumbnails and .thumbnails. These are name filters, not a test that files are disposable. Excluding them can skip wanted photos or other files. Nothing is deleted or cleaned.

Save to your PC

Each run creates a new megahy-backup dated folder. Existing backups are not overwritten. Keep enough space for your selection.

Pause waits for the current ADB operation to finish, which may take time for a large file. Resume continues this running session only. Stop ends it; the next run is a new backup, not a continuation.

One-time setup

1. Add Google's ADB. Extract the official Windows Platform-Tools folder next to START-megahy-backup.cmd.

2. Connect one phone. Enable ordinary USB debugging, use a data cable, unlock the phone and allow this PC. No root or extra phone app is needed.

3. Keep the console open. Do not run two backup apps against the same phone at once. Let an older backup finish before starting this version.

Pause is a checkpoint

"Pausing safely" means an operation is still finishing. "Paused" means the app is waiting between device operations. A partial transfer is never counted as verified.

Keep the phone connected and idle while paused. Unplugging is not made safe by Pause. Resume re-checks the pinned device; if it is unavailable, the run ends incomplete. If you reconnect the same phone, later hashes can still fail if a file changed. This is not a snapshot.

Know the boundary

  • Copied files: original bytes and formats. Windows may still need a codec to open an unusual format. Some filenames are safely mapped for Windows.
  • Provider archives: contacts as vCards, SMS/calls as JSON and CSV, MMS as metadata and binary parts. Not tested for Android restoration.
  • Not extracted: private app data, app chats, authenticator secrets, logins, eSIMs and device settings. Secure folders, work profiles, cloud-only or unreadable files may be absent.
  • Existing MIUI backups: only copied if already readable and within your selection. No MIUI backup is created.
What does verification mean?

For each verified storage file, SHA-256 matched on the phone before and after copying and on the PC. The report checks copied bytes, not discovery completeness. Provider archives are not source-versus-PC hash verified.

Read REPORT.txt, report.json, the category report and manifest.jsonl. Unselected categories are explicitly marked "not selected". Failed transfers may remain as .partial files, never as verified files.

Local and read-only. No backup upload, analytics, delete or reset function. Backup files are not encrypted. Protect your PC disk and disable USB debugging when finished.
