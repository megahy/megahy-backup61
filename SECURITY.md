# Security and privacy reports

No public support address or repository exists yet. Before publication, the owner should choose and approve a private vulnerability-reporting route, such as GitHub private vulnerability reporting. Do not post vulnerability details or private backup contents publicly to obtain help.

When reporting an ordinary failure, include the app version, Windows version, phone model/Android version, the operation and a redacted error. Do not include phone serial numbers, contact lists, messages, file inventories, console URLs or raw backup data.

This is a release candidate with no service-level or response-time promise. Do not treat an absence of reported vulnerabilities as a security certification.
